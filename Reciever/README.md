# CarView

For first-time setup, keys and sender instructions, follow the [CarFramework operating guide](../README.md).

To launch CarView from this folder:

```bash
bun install
bun run start
```

Open **Connection**, check the detected keys and Python executable, then click **Start receiver** before starting the sender. Use **Stop** to stop receiving. You only need `bun install` on first setup or after dependencies change.

For help, see [troubleshooting](../docs/troubleshooting.md).
